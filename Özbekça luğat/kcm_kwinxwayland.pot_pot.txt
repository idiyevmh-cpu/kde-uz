Legacy X11 apps with global shortcuts and other features accessed while running in the background need to be able to listen for keystrokes all the time.<nl/><nl/>If you use any of these apps, you can choose your preferred balance of security and compatibility here. - Fondagi rejimda işlayotganda global tezkor tugmalar va boşqa funksiyalarga ega eski X11 ilovalari har doim tugmalar bosilişini tinglay olişi kerak.<nl/><nl/>Agar uşbu ilovalardan birortasini işlatsangiz, bu yerda xavfsizlik va muvofiqlikning afzal körgan muvozanatini tanlaşingiz mumkin.
Listening for keystrokes: - Tugmalar bosilişini tinglaş:
Prohibited - Taqiqlangan
Most secure; global shortcuts will not work in X11 apps - Eng xavfsiz; X11 ilovalarida global tezkor tugmalar işlamaydi
Only the Meta, Control, Alt, and Shift keys - Faqat Meta, Control, Alt va Shift tugmalari
High security; push-to-talk and other modifier-only global shortcuts will work in X11 apps - Yuqori xavfsizlik; X11 ilovalarida push-to-talk va faqat modifikatorli boşqa global tezkor tugmalar işlaydi
As above, plus any key pressed while the Control, Alt, or Meta key is also pressed - Yuqoridagi kabi, şuningdek Control, Alt yoki Meta tugmasi bosib turilganda bosilgan har qanday tugma
Moderate security; all global shortcuts will work in X11 apps - Örtaça xavfsizlik; barça global tezkor tugmalar X11 ilovalarida işlaydi
Always allowed - Har doim ruxsat berilgan
Least secure; all X11 apps will be able to see any text you type into any application - Eng kam xavfsiz; barça X11 ilovalari siz istalgan ilovada yozgan har qanday matnni köra oladi
Note that using this setting will reduce system security and permit malicious software to steal passwords and spy on the text that you type. Make sure you understand and accept this risk. - Eʼtibor bering, bu sozlamadan foydalaniş tizim xavfsizligini kamaytiradi va zararli dasturlarga parollarni öğirlaş hamda siz yozayotgan matnni kuzatiş imkonini beradi. Uşbu xavfni tuşunganingiz va qabul qilganingizga işonç hosil qiling.
