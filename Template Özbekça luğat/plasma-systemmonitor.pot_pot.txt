CPU Scheduler - CPU rejalaştiruvçisi
Normal - Oddiy
The standard time-sharing scheduler for processes without special requirements. - Maxsus talablarsiz jarayonlar uçun standart vaqt taqsimoti rejalaştiruvçisi.
Batch - Paketli (Batch)
Process is mildly disfavored in scheduling decisions, for CPU-intensive non-interactive processes. - CPU-ni köp talab qiladigan nointeraktiv jarayonlar uçun rejalaştirişda jarayonga biroz kamroq ustunlik beriladi.
Round robin - Round-robin (navbatma-navbat)
Process will run whenever runnable, with timeslicing. - Jarayon vaqt bölaklari bilan işga tayyor bölgan istalgan paytda bajariladi.
FIFO - FIFO (birinçi kelgan - birinçi ketadi)
Process will run whenever runnable, with no timeslicing. - Jarayon vaqt bölaklarisiz işga tayyor bölgan istalgan paytda bajariladi.
I/O Scheduler - I/O rejalaştiruvçisi
Normal - Oddiy
Process' priority is based on the CPU priority. - Jarayon prioriteti CPU prioritetiga asoslanadi.
Idle - Böş turgan (Idle)
Process can only use the hard disk when no other process has used it very recently. - Jarayon qattiq diskdan faqatgina boşqa heç bir jarayon undan yaqinda foydalanmagan bölsa foydalana oladi.
Best Effort - Eng yaxşi imkoniyat (Best Effort)
Process is given higher priority to access the hard disk than normal. - Jarayonga qattiq diskka kiriş uçun odatdagidan yuqoriroq prioritet beriladi.
Real Time - Haqiqiy vaqt (Real Time)
Process gets immediate access to the hard disk whenever needed, regardless of what else is going on. - Jarayon nima bölayotganidan qatʼi nazar, kerak bölganda qattiq diskka darhol kiriş imkoniga ega böladi.
