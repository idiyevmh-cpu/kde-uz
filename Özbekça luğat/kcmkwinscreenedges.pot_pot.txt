&Corner barrier: - &Burçak tösiği:
Here you can enable or disable the virtual corner barrier between screens. The barrier prevents the pointer from moving to another screen when it is already touching a screen corner. This makes it easier to trigger user interface elements like maximized windows' close buttons when using multiple screens. - Bu yerda siz ekranlar orasidagi virtual burçak tösiğini yoqişingiz yoki öçirişingiz mumkin. Tösiq körsatkiç ekran burçagiga tegib turganda uning boşqa ekranga ötib ketişini oldini oladi. Bu bir neçta ekranlardan foydalanganda kattalaştirilgan oynalarning yopiş tugmalari kabi interfeys elementlarini işga tuşirişni osonlaştiradi.
Prevents the pointer from crossing at screen corners. - Körsatkiçning ekran burçaklaridan ötib ketişini oldini oladi.
&Edge barrier: - &Çet tösiği:
Here you can set size of the edge barrier between different screens. The barrier adds additional distance you have to move your pointer before it crosses the edge onto the other screen. This makes it easier to access user interface elements like Plasma Panels that are located on an edge between screens. - Bu yerda turli ekranlar orasidagi çet tösiği hajmini belgilaşingiz mumkin. Tösiq körsatkiç boşqa ekranga çetdan ötişidan oldin bosib ötişi kerak bölgan qöşimça masofani qöşadi. Bu ekranlar orasidagi çetda joylaşgan Plasma panellari kabi foydalanuvçi interfeysi elementlariga kirişni osonlaştiradi.
