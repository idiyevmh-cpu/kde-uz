This tool allows you to set the window decoration theme for the currently active session, without accidentally setting it to one that is either not available, or which is already set. - Uşbu vosita mavjud bölmagan yoki allaqaçon örnatilgan mavzuni adaşib örnatib qöymasdan, joriy faol seans uçun oyna bezaklari mavzusini sozlaş imkonini beradi.
The name of the window decoration theme you wish to set for KWin. Passing a full path will attempt to find a theme in that directory, and then apply that if one can be deduced. - KWin uçun örnatmoqçi bölgan oyna bezaklari mavzusi nomi. Töliq yölni körsatiş öşa jilddan mavzuni topişga va uni qöllaşga harakat qiladi.
Show all the themes available on the system (and which is the current theme) - Tizimda mavjud bölgan barça mavzularni körsatiş (va ulardan qaysi biri joriy mavzu ekanligini)
